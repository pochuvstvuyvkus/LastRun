**Нельзя копировать** ассеты, логотипы и тексты оригинала дословно (никаких «Store», «ALIEN SPIN», «VIP» и т.п.). Делаем тот же жанр, настроение и схему интерфейса, но своими средствами и своими русскими надписями («МАГАЗИН», «ПРОДАТЬ», «ВЕРСТАК», «до конечной» и т.д.).

**Решения пользователя:**
1. Автобус — как в оригинале: едет **только вперёд по дороге**, газ/тормоз, **без руля, без свободной езды, без спидометра и панелей**. В депо автобус **собирают**: прикрепить 4 колеса, закинуть топливо в печь.
2. Лобби — автобусы-площадки + большая кнопка «Играть» (сразу одиночный старт).
3. Графика — строим сами (детали Roblox, мрачный стиль) **и** поддерживаем модели из Toolbox (если игрок положил их в `ServerStorage.LR_Assets`).
4. Оставить: сон и зомби-будильник, цели и события, уровни и награды, оружие (продумать анимации; «лопатой бить нельзя» — удары должны ощутимо попадать по чему-то), качественные звуки.
5. Убрать: свободную езду, границы как игровую механику автобуса, миникарту (уже удалена), покупку типов автобусов, прокачку вооружения автобуса уровнями (заменено деталями), панель автобуса в HUD, маршрутную полосу.

**Проверки как в v2:** `python3 tools/luacheck.py src` (0/0), `python3 tools/xref.py` (0 problems), `python3 build.py --out <scratchpad>/build_<ключ>.rbxlx --no-project`. ## 2. Визуальный стиль (для A, B, C, D, E)

- Освещение: `Lighting.Technology = Future` (выставлено в сборке). Атмосфера: пасмурно и туманно днём (Atmosphere Density ≈ 0.35–0.45, Haze 2–3, Color серо-голубой), тёмная синяя ночь, но читаемая. ColorCorrection: Saturation −0.2…−0.3, Contrast +0.1, лёгкий холодный оттенок. Bloom (Intensity ≈ 0.6, Size 24, Threshold ≈ 1.4) — чтобы неон светился. Лёгкие SunRays днём.
- Материалы: Brick (тёмно-кирпичный), Concrete/Slate (серая плитка; швы — тонкие детали или SurfaceGui-сетка), CorrodedMetal/CorrugatedMetal (ржавчина 150,90,40), DiamondPlate (полы), Asphalt (тёмная дорога, выцветшая разметка), WoodPlanks, Fabric (камуфляж — несколько цветных пятен). Рабица — тонкая сетка из деталей с прозрачностью; колючая проволока — спирали из мелких цилиндров.
- Вывески: SurfaceGui + TextLabel неонового цвета (зелёный 80,255,120 / оранжевый 255,160,60 / жёлтый 255,210,90) + PointLight рядом, `LightInfluence = 0`.
- Сосны — высокие, тёмные, из стопки конусов (Wedge-пары), стволы тонкие.
- Никаких ярких «игрушечных» цветов, неоновых колец под добычей и т.п.; редкость добычи — тонкая подсветка.
- Метки объектов в мире: CollectionService-тег **`LR_Waypoint`** на BasePart (или Model с PrimaryPart) + атрибуты `WaypointLabel` (строка, КАПСОМ), `WaypointColor` (Color3, опц.), `WaypointMaxDistance` (число, по умолчанию 90). Рисует D (белый текст с обводкой + расстояние «46m» с маленьким ромбом).
- Подсказка-задание игроку: атрибуты игрока `GuideTitle` («Обучение»/«Цель»), `GuideText`, `GuideTarget` (Vector3 или nil). Рисует D: панель над хотбаром + светящиеся жёлтые шевроны на земле от игрока к `GuideTarget`. Если `GuideText` пуст — D берёт ближайшую активную цель из `ObjectivesSync`.

## 3. Контракты

### 3.1 Автобус и экономика (A)
- **Движение только вперёд по дороге**: `Bus.S` растёт/уменьшается, `Bus.D = 0`, курс = касательная дороги (как v1). Водитель: W — газ, S — тормоз/медленный задний ход. `DriveInput(throttle, steer)` — `steer` игнорируется. Препятствия: мягкие — таран; твёрдые завалы (`gate`/breakable от B) — автобус упирается, пока их не разобьют.
- **Модель**: ржавый оранжевый каркас школьного автобуса (CorrodedMetal/CorrugatedMetal), тёмная рама, выбитые окна с рамами, круглые жёлтые плафоны (Neon + PointLight) в салоне, пол DiamondPlate, печь с окошком огня (Neon + Fire) и табличкой «ТОПЛИВО» у водителя, кресло водителя, 2 базовые койки, ящик ремонта, **верстак не в автобусе** (верстаки есть в депо и на станциях). Лестница на крышу (TrussPart кратно 2). Фары. Высота с поручнями ≤ 14.
- **Сборка**: в новом заезде у автобуса 0 колёс. На 4 слотах — полупрозрачные «призраки» колёс + подсказка «Прикрепить колесо» (нужен предмет `bus_wheel`). 4 колеса лежат в депо: `S.Props.DepotWheelSpawns()` → список CFrame (B) → `S.Loot.SpawnItem("bus_wheel", 1, cf, parent)`. Пока нет 4 колёс или топлива — автобус не едет (уведомление водителю, чего не хватает).
- **Детали**: `shared/BusParts.lua` — слоты `wheel`(4), `side`(6 окон), `front`(1), `roof`(2), `lamp`(2), `cabin`(3). У каждого свободного слота подсказка «Прикрепить: <название слота>» — прикрепляет первую подходящую деталь из инвентаря игрока. Визуал каждой детали. Эффекты: броня добавляет MaxHP и закрывает окно (зомби не пролезают), решётки — множитель тарана/пилы, турель — автоматическая стрельба, прожектор — замедление зомби ночью, койка — +1 спальное место (`S.Sleep.RegisterBed`), сигнализация — будильник. Звук/эффект прикрепления.
- **Совместимость API** (используется другими модулями — сохранить): `S, D, V, HP, MaxHP, Fuel, FuelMax, Model, Root, Driver, Position, Build(startS), Destroy(), Update(dt), IsInside(pos), IsNear(player, r), IsNearTank(player), InHeadlights(pos), GetSpawnCFrame(i), Damage(amount, info), Repair(amount), RepairWith(player), RefuelWith(player, itemId), PublishState(), HasUpgrade(id), GetLevel(id), ApplyUpgrade(id) -> false, "…"`. `GetLevel` отображает детали на старые ключи: `"lights"` = число прожекторов, `"alarm"` = 1 если есть сигнализация, `"bunks"` = число доп. коек, `"ram"` = 1 шипы / 3 пилы, `"autoturret"` = число турелей, иначе 0.
- **Атрибуты** GameState: `BusHP, BusMaxHP, Fuel, FuelMax, Km, Speed, DriverName, BusReady (bool), BusWheels (0–4), Upgrades` (строка «id:level» по карте выше).
- **Обучение в депо** (атрибуты `GuideTitle/GuideText/GuideTarget` каждому игроку в заезде, пока автобус в депо): 1) «Прикрепите все четыре колеса к автобусу» (цель — ближайшее лежащее колесо, если у игрока его нет, иначе ближайший пустой слот); 2) «Закиньте топливо в печь автобуса» (цель — печь; топливо: уголь лежит у депо — попросите B или спавните сами рядом с автобусом 2 угля); 3) «Сядьте за руль и поезжайте» (цель — кресло). После выезда из депо — очистить атрибуты (дальше D берёт цели биома).
- **Метки** `LR_Waypoint`: печь «ТОПЛИВО», пустые слоты колёс «КОЛЕСО», кресло «ЗА РУЛЬ» (когда готов), ящик «РЕМОНТ».
- **WorkbenchService**: убрать `UpgradeBus`/вооружение уровнями; крафт по `Recipes` (включая детали автобуса), улучшение оружия, укрепления и инструменты — как v2. Верстак-подсказка «Изготовить», метка `LR_Waypoint` «ИЗГОТОВИТЬ».
- **ShopService**: вкладки Продать / Припасы / Материалы / Детали (`Items.Shop.parts`) / Патроны / Оружие; ремонт автобуса за деньги. Метки «МАГАЗИН»/«ПРОДАТЬ» ставит B на объекты депо, торговцы станций — D… (станции не трогаем, у них уже есть подсказка).
- **LootService**: как v2 (ключи памяти, `OnItemPickup`), предметы на земле — без неоновых колец: аккуратная тонкая подсветка по редкости (SelectionBox/Highlight не использовать массово — лимит Highlight 31).

### 3.2 Мир и визуал (B)
- **Депо** (полностью заново, по кадрам оригинала, своими средствами): улица вдоль начала дороги (тротуар, бордюр), 2-этажное кирпичное здание магазина с плиточным первым этажом и открытыми гаражными воротами, внутри полки/стенды с табличками «ОРУЖИЕ», «ПАТРОНЫ», «ДЕТАЛИ», «ПРИПАСЫ», зелёная неоновая вывеска «МАГАЗИН» над воротами, внутри прилавок с оранжевой неоновой надписью «ПРОДАТЬ» и NPC-торговец (или без NPC — стойка); рядом навес с верстаком; вышки, забор из рабицы с колючей проволокой, камуфляжная палатка, покрышки, ящики, фонари, высокие сосны, горы и тоннель на выезде. Автобус стоит на дороге у магазина (s = 70, d = 0) — ничего не должно пересекаться с ним (корпус |d| ≤ 7, длина ±23) и нависать ниже высоты 16 над ним.
  - Регистрация: `S.Stations.RegisterTrader(partMagazin, {name = "Магазин депо", kind = "depot"})` (и для «ПРОДАТЬ» тот же торговец/вторая стойка), `S.Workbench.RegisterBench(benchPart, "depot")`, теги `LR_Waypoint` («МАГАЗИН», «ПРОДАТЬ», «ИЗГОТОВИТЬ»).
  - `Props.DepotWheelSpawns() -> {CFrame, …}` (≥4 точек на земле рядом с автобусом/магазином) и `Props.DepotFuelSpawns() -> {CFrame, …}` (≥2).
  - Доска выбора класса в депо убирается (классы — в лобби).
- **Биомы**: подтянуть качество декора к тому же мрачному стилю; сосны как в оригинале; здания с деталями (окна с рамами, карнизы, водостоки, кондиционеры, решётки).
- **Дорога**: никаких постоянных твёрдых препятствий, которые нельзя убрать. Разрешено: мягкий мусор (таран), редкие **завалы** (раз в ~3–4 км, предупреждающий знак за 60 studs): Model с атрибутами `Breakable = true`, `HP`, `MaxHP`, зарегистрирован как hard `gate` («Завал — разбейте его») в Obstacles. `Props.DamageBreakable(model, amount, attacker) -> destroyed(bool), kind` (kind = "wood"/"metal"/"stone"): при HP ≤ 0 — разлёт обломков, удаление препятствия. Вызывает E.
- **Границы**: оставить стены и страховку для игроков/зомби (упрощённо), убрать всё, что было для свободной езды автобуса.
- **AssetLibrary** (`server/AssetLibrary.lua`): `AssetLibrary.Has(category)`, `AssetLibrary.Spawn(category, cframe, rng, parent) -> Model|nil` — клон случайной модели из `ServerStorage.LR_Assets.<category>` (Folder). Категории: `Trees`, `Rocks`, `Buildings`, `Props`, `Vehicles`, `Fences`, `Lamps`. Клон: низ ограничивающего бокса на y = cframe.Y, все BasePart Anchored, CollisionGroup "World", CanQuery по умолчанию; возвращает модель, радиус (для Obstacles). Props использует библиотеку, если в категории есть модели, иначе процедурный вариант.
- **DayNight**: стиль из раздела 2 (Bloom, ColorCorrection, SunRays), биомы и кровавая луна сохраняются.

### 3.3 Лобби и заезд (C)
- **Мир лобби** (около `CFrame.new(0, 0, -4000)`): ночная площадь, мокрый асфальт, фонари, туман, сосны, забор. В ряд **6 ржавых школьных автобусов-площадок** (своя модель, похожая на автобус заезда). У каждого — зона посадки (невидимая неколлизионная деталь у двери/перед автобусом). Над автобусом BillboardGui: «Пусто» / «Сбор 2/4 · старт через 12 с» / «Отправление…». Один-два автобуса — «ТЯЖЁЛЫЙ»/«КОШМАР» (подпись; закрыт, если сложность не открыта у игрока — сообщение).
- Вход в зону = вход в группу этого автобуса (первый — лидер). Выход из зоны = выход из группы. Отсчёт `Config.PartyStartTimeout`-подобный (20 с) стартует при первом игроке; лидер может нажать «Отправиться сейчас» (кнопка в LobbyUI, видна только внутри зоны). По окончании отсчёта — старт группы (живой сервер: резервный сервер + телепорт; Studio/ошибка: локальный `Run.NewRun({difficulty})`).
- **Интерфейс лобби** (LobbyUI): слева сверху полоса уровня («Уровень N  xp/next»), слева крупные квадратные кнопки (тёмные, белая обводка, крупный текст + простая иконка из Frame): **КЛАССЫ** (окно выбора класса — перенести выбор класса в лобби, `SelectClass` должен работать в лобби: request к A/ShopService), **НАГРАДЫ** (ежедневные награды — ProgressUI), **ПРОФИЛЬ** (уровень, заезды, победы, лучший км, убийства), **ПРИСОЕДИНИТЬСЯ** (ввод 4-буквенного кода группы → игрока переносит в зону автобуса этой группы); слева снизу билеты с иконкой; **снизу по центру большая зелёная кнопка «ИГРАТЬ»** — мгновенный одиночный старт; справа снизу «Пригласить друзей» (`SocialService:PromptGameInvite`, в pcall). Всё с UIScale.
- Убрать витрину автобусов, покупку/выбор автобусов, окно списка групп (группы — только через автобусы и код).
- **В лобби у игроков нет оружия** (E убирает инструменты при `S.Run.Mode == "lobby"`); боевая камера не включается.
- **RunManager**: `NewRun(settings)` → `Bus.Build(70)` (без типа автобуса), сложность из настроек; остальное как v2. Выдача pending-наград — как v2.
- **ProgressUI**: окно ежедневных наград и тост повышения уровня в новом стиле; в заезде полосу уровня не показывать (в лобби её рисует LobbyUI).

### 3.4 Интерфейс (D)
- **Тема** (UI.lua): тёмные полупрозрачные панели (чёрный, прозрачность ≈ 0.45), тонкая светлая обводка, углы 4 px, белый GothamBold/GothamBlack текст с обводкой, акцент оранжевый (255,170,60) для заголовков, зелёный — деньги.
- **HUD заезда** (как схема оригинала, своя графика):
  - сверху по центру мелко: «95 749 м до конечной» = `(Config.RouteKm − Km) × 1000` м (атрибут Km от A).
  - слева: деньги (зелёная «купюра» из Frame + значение), голод «96%» (круглый бейдж), бодрость «80%» (бейдж), здоровье — тонкая красная полоска или бейдж; эффекты мелкими плашками.
  - снизу по центру: **свой хотбар** (отключить стандартный Backpack через `StarterGui:SetCoreGuiEnabled(Enum.CoreGuiType.Backpack, false)` в LocalScript): кнопка рюкзака (Tab) + слоты инструментов с названиями, выделение экипированного, клавиши 1–9, клик/тап экипирует (`Humanoid:EquipTool`).
  - над хотбаром — панель задания (оранжевый заголовок + белый текст) из `GuideTitle/GuideText`, иначе ближайшая цель биома.
  - справа снизу: «Спринт [Shift]»; за рулём: «W — газ · S — тормоз · Пробел — встать».
  - тосты сверху по центру, уведомления слева, полоса босса, баннер события (EventsUI) — компактно, в том же стиле.
  - Убрать: маршрутную полосу, панель автобуса, большие панели статов, большую панель подсказок (F1 — компактный список).
- **ObjectivesUI**: метки `LR_Waypoint` + метки активных целей (название + «46m» + ромб), шевроны на земле к `GuideTarget` (клиентские Neon-детали, CanCollide/CanQuery false, анимация бегущей волны, до 25 шевронов, шаг ≈ 3 studs, по рельефу — рейкаст вниз), компактный трекер целей биома справа.
- **Panels** (инвентарь, магазин, класс, итоги), **WorkbenchUI** (вкладки Крафт / Детали автобуса / Улучшить оружие), **SleepClient** — перерисовать в новой теме. Выбор класса открывается из лобби (C вызывает `C.Panels.OpenClassSelect()` — оставить публичным и убрать проверку «только в депо» на клиенте, если есть).

### 3.5 Оружие и звук (E)
- **Нет оружия в лобби**: `WS.RefreshTools` удаляет все инструменты, если `S.Run.Mode == "lobby"`; при старте заезда выдаёт.
- **Ближний бой**: сервер бьёт зомби **и разрушаемые объекты** (`S.Props.DamageBreakable` для моделей с атрибутом `Breakable` в зоне удара; ящики с лутом можно не трогать). После каждого удара — `HitFx` ближайшим клиентам `{pos, kind ("flesh"/"wood"/"metal"/"stone"/"air"), weaponId, attacker}`. Клиент: искры/кровь/щепки (частицы из деталей или ParticleEmitter без текстур), звук, короткий hit-stop (замедление анимации ~0.06 с), толчок камеры, у лопаты — лязг. Промах — «свист».
- **Анимации** (CharAnimator): переделать удары на выразительные — замах (anticipation) → резкий удар → доводка → возврат; у каждого оружия свой набор (лопата: широкий горизонтальный + рубящий сверху; бита; мачете; топор; катана; кувалда), шаг/выпад корпусом, наклон; ходьба с оружием, прицеливание, отдача, перезарядка, лук. Trail на лезвии/кромке (Trail + 2 Attachment, без текстур, цвет по оружию, только во время удара). Своя анимация видна сразу, чужим — через `PlayAnim`.
- **Огнестрел**: вспышка, гильза (маленькая деталь, отлетает), трассер, отдача, звук.
- **Модели оружия** (WeaponModels): узнаваемые — лопата со штыком и черенком с Т-ручкой, бита с гвоздями, мачете, пожарный топор, катана, кувалда, револьвер, дробовик, автомат, снайперка, лук, арбалет, бутылка — аккуратные пропорции, материалы, мелкие детали (заклёпки, обмотка).
- **Зомби** (ZombieAnim): вздрагивание при попадании (по `HitFx`/HealthChanged), рывок атаки, падение при смерти; периодическое рычание ближайших зомби (звук).
- **Звуки** (Effects): только через `shared/Sounds.lua` (`Sounds.Get(key)` → nil = тишина, никаких ошибок). 3D-звуки оружия/зомби/ударов; луп двигателя автобуса, когда автобус едет (громкость/высота от атрибута `Speed`); луп огня у печи; эмбиент ветра/ночи/дождя по биому и времени суток; звуки интерфейса (клик, подбор, продажа, уровень). Если нужных ключей нет в `Sounds.lua` — добавьте в `requests` (id заполнит архитектор).

## 4. Сетевые события
