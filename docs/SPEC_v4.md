## 2. Контракты

### 2.1 Инвентарь-слоты (INV)
- Данные игрока: `d.Slots[1..28]` — 1..10 хотбар («в руках»), 11..28 рюкзак. Элемент слота: `nil` или
  `{ kind = "item", id = itemId, count = n }` или `{ kind = "weapon", id = weaponId, level = n, mag = n }`.
  `d.Active` — индекс активного слота хотбара (1..10) или 0 (пустые руки).
- Размер стопки: поле `stack` в `Items.List` (добавить всем): материалы 20, патроны 120 (в штуках), еда 5, медицина 5, уголь 10, канистра/бочка 1, детали автобуса 1, ценности 10, метательное 5, ключ 1, инструменты/укрепления 3. Оружие — 1 в слоте.
- **Совместимость (сохранить, используется везде)**: `PD.Count(player, itemId)` (сумма по слотам), `PD.AddItem(player, itemId, count)` → **число добавленного**; всё, что не влезло, **выпадает на землю у игрока** (через `S.Loot.SpawnItem`), возвращаемое значение истинно, если добавлено >0 или выброшено; `PD.RemoveItem(player, itemId, count) -> bool` (сначала из рюкзака, потом из хотбара, активный слот — последним), `PD.GiveWeapon(player, weaponId, opts{level, mag})`, `PD.RemoveWeapon(player, weaponId) -> {level, mag}`, `PD.GetWeaponLevel`, `PD.SetWeaponLevel`, `PD.SyncInventory`. Поля `d.Inventory` (карта id→сумма), `d.Weapons` (id→true), `d.WeaponOrder`, `d.WeaponLevels`, `d.Mags` — **поддерживать как производные** (другой код читает их).
- **Новое API**: `PD.GetSlots(player)`, `PD.GetActive(player) -> index, entry`, `PD.SetActive(player, index)` (0 = убрать из рук; сервер экипирует инструмент через WeaponService), `PD.MoveSlot(player, from, to, count)` (перенос/обмен/слияние/деление), `PD.DropSlot(player, index, count)` (выпадает перед игроком), `PD.ConsumeActive(player, n) -> bool`, `PD.FindFreeHotbar(player)`.
- **Подбор** (`LootService.Pickup`): предмет кладётся в хотбар (сначала докладывается в стопки, затем в первый свободный слот 1..10, затем рюкзак 11..28) и **становится активным** (в руках) — `PD.SetActive`. Если всё занято — «Инвентарь полон», предмет остаётся лежать. Оружие с земли — так же.
- Удалённое событие `InventoryAction(action, data)`: `equip {slot}`, `unequip`, `move {from, to, count}`, `drop {slot, count}`, `use {slot}` (использовать предмет из слота как из рук), `split {from, to, count}`. Валидировать всё.
- Событие клиенту `Inventory` — **аргументы**: `(countsMap, weaponOrder, weaponLevels, slots, active)` (первые три — как раньше).
- **Бодрость убрать полностью**: из PlayerData (расход, микросны, обмороки, атрибут `Energy` больше не ставить), из Items (кофе → «Кофеин» +скорость, энергетик → короткий «Адреналин» + потом «Упадок сил», травяной чай → +15 здоровья), из Classes («Лунатик» → «сон лечит вдвое быстрее, разбуженный — ярость»), из StatusEffects (у «Выспался» только урон), из SleepService (лечь можно всегда, если не в бою и рядом нет зомби; сон лечит ~2 HP/с; «Выспался» — если проспал ≥ 25 с без помех; ночь ускоряется, когда спят все; угроза/пробуждение как раньше; обморока нет).
- ShopService/WorkbenchService: покупка/крафт → `AddItem` (переполнение выпадает рядом); продажа/расход → `RemoveItem`/`Count`. Верстак: «Детали автобуса» и прочее — как v3.

### 2.2 Предметы в руках, первое лицо, удары (HANDS)
- **Инструменты**: у каждого непустого слота хотбара 1..10 — Tool в Backpack (сервер создаёт/обновляет/удаляет по `d.Slots`), атрибуты `Slot`, `ItemKind` ("weapon"/"item"), `ItemId`, `Count`, `Level`, `Mag`, `MaxMag`, `WeaponId` (для оружия — как раньше). Слоты рюкзака 11..28 инструментов не имеют. `WS.RefreshTools(player)` синхронизирует по слотам; в лобби — пусто. Экипировка: клиент может сам вызвать `Humanoid:EquipTool` (сервер ловит появление Tool в персонаже и ставит `PD.SetActive`), или сервер `PD.SetActive` → `WS.EquipSlot(player, i)`.
- **Модели предметов** (`shared/ItemModels.lua`, новый): `ItemModels.Build(itemId) -> Model` (детализированные: колесо с диском и протектором, уголь-кусок, канистра, бочка, консервы, чипсы, бутылка, термос, бинт, аптечка, шприц, патроны-коробки, стрелы, болты, бутылка с тряпкой, металлолом, изолента, доски, ткань, верёвка, батарейки, пружины, труба, порох, микросхема, ремкомплект, фонарь, баррикада-свёрток, капкан, ключ, ценности, детали автобуса). `ItemModels.MakeTool(itemId, count)`, `ItemModels.MakeDisplay(itemId, cframe)` (для лута на земле — LootService может перейти на него: request INV). Точка хвата и ориентация как у оружия (-Z вперёд, +Y вверх).
- **Использование предмета в руке** (ЛКМ / Tool.Activated): оружие — атака; еда/медицина — съесть/вылечиться (анимация, `PD.ConsumeActive`); топливо — если рядом печь автобуса (`S.Bus.IsNearTank`) — закинуть; деталь автобуса — если рядом подходящий слот — прикрепить (`S.Bus.AttachItem(player, itemId)` — есть у BUS); укрепления — поставить; инструменты — как раньше; ценности — «осмотреть» (тост с ценой). Сервер валидирует. Q — выбросить предмет из руки (1 шт., Shift+Q — всю стопку). Колёсико мыши / 1–0 — смена слота (клиент).
- **Первое лицо**: в заезде `player.CameraMode = Enum.CameraMode.LockFirstPerson` (сервер ставит при спавне в режиме run; клиент — страховка), в лобби `Classic` (от третьего лица). За рулём — тоже первое лицо. Боевая камера v2/v3 (плечо, LockCenter) не нужна в первом лице — удалить/отключить.
- **ViewModel** (`client/ViewModel.lua`): от первого лица рисует руки (рукава цвета рубашки персонажа, кисти цвета кожи) и модель предмета из активного слота, привязанные к камере (CFrame каждый RenderStepped, детали `CanCollide/CanQuery/CanTouch=false`, `CastShadow=false`, в `workspace.CurrentCamera`). Покачивание при ходьбе/беге, отставание при повороте мыши, анимации: удары для каждого оружия ближнего боя (замах → удар → доводка, как в CharAnimator), выстрел/отдача/перезарядка, натяжение лука, бросок, еда/питьё, лечение, установка/прикрепление, смена предмета (опускание/подъём). API: `ViewModel.Play(name, duration)`, `ViewModel.SetItem(entryOrNil)`. Скрыт в лобби, мёртвым, спящим, при открытом окне. Тело персонажа в первом лице скрыто штатно; инструмент в руке персонажа — скрыть локально (`LocalTransparencyModifier = 1`), чтобы не двоилось.
- **Удары по всему**: ближний бой на сервере — луч/сфера из головы по направлению взгляда (клиент шлёт `aim`), дальность оружия: попал в зомби → урон; в модель с `Breakable` → `S.Props.DamageBreakable`; во что угодно ещё (стены, машины, деревья, автобус, лут, земля) → `HitFx` с видом материала (`Weapons.MaterialKind`), незакреплённые детали получают толчок. Промах в воздух — свист. Звук попадания **всегда** (Effects по виду: flesh/wood/metal/stone/glass/dirt → ключи Sounds). Огнестрел/стрелы — то же по месту попадания. Клиент предсказывает эффект сразу.
- **CharAnimator**: позы от третьего лица для других игроков, держащих любые предметы (предмет в руке виден другим).

### 2.3 Tab-меню и HUD (UI)
- **Tab**: полноэкранное тёмное окно в стиле игры: слева — персонаж (класс, здоровье, сытость, деньги), по центру — **сетка рюкзака 6×3 = 18 слотов**, снизу — **ряд хотбара 10 слотов** (как на экране), справа — карточка выбранного предмета (крупная 3D-иконка ViewportFrame из `ItemModels`/`WeaponModels`, название, редкость, описание, цена продажи, кнопки «Использовать», «В руки», «Выбросить», «Разделить», «Передать»). **Перетаскивание** мышью/пальцем между слотами (`InventoryAction move`), двойной клик — в руки, ПКМ — быстро использовать. Количество в углу слота, рамка редкости, пустые слоты видны. Всё с UIScale.
- **Хотбар HUD**: 10 слотов внизу по центру (номера 1–0), 3D-иконки, количество, выделение активного, клик/клавиши/колесо — экипировка (через `InventoryAction equip`), слот «рюкзак» слева открывает Tab.
- Убрать бейдж бодрости и всё про бодрость (в том числе SleepClient: виньетка усталости, текст «Бодрость»). В HUD показать небольшой индикатор времени суток (солнце/луна + «07:40») рядом со строкой «… м до конечной».
- WorkbenchUI и магазин (Panels) — адаптировать к слотам (наличие материалов = `C.State.Inventory`, как раньше).
- Прицел от первого лица: маленькая точка по центру; для огнестрела — крестик.

### 2.4 Автобус (BUS)
- **Колёса крутятся**: колесо — отдельная деталь, соединённая с корпусом **Motor6D** (Part0 — корень, C0 — точка крепления); клиент (BusClient) каждый кадр (RunService.Stepped) ставит `Motor6D.Transform = CFrame.Angles(угол, 0, 0)` (ось вращения — ось цилиндра), угол += скорость/радиус·dt, скорость из атрибута `Speed` / `Config.Bus.SpeedDisplayMult` (знак по направлению). Призраки колёс не крутятся.
- `Bus.AttachItem(player, itemId) -> ok, message` — прикрепить деталь из руки к ближайшему подходящему пустому слоту (≤ 12 studs), расходовать через `PD.RemoveItem` (сначала из активного слота — INV обеспечит порядок). Подсказки на слотах остаются.
- Печь: `Bus.RefuelWith(player, itemId)` — как раньше (HANDS вызывает при использовании топлива в руке).
- Детализация: заклёпки, ржавые пятна, внутренние поручни, провода, номер/табличка, тряпки на сиденьях, фары с отражателями, подножка, выхлопная труба с дымом при движении, пыль из-под колёс; камера водителя от первого лица должна видеть приборку и дорогу (без мешающих деталей перед глазами).

### 2.5 Мир, день/ночь, станции (WORLD)

### 2.6 Зомби и лобби (ENEMY)
- **Плавный рост**: `ZS.SpawnTick` — желаемое число бродячих = `(StartDesired + PerKm·км + PerKm2·км²) · biome.spawnMult · CountMult · (1 + 0.35·(игроки−1))`, ночь ×1.5, но не больше cap; первые `SpawnGraceKm` км после депо — без случайных спавнов; размер группы интерполируется от `GroupStart` к `GroupLate` по доле пути; зомби в зданиях — от `POICountStart` к `POICountLate`. Орды станций и события — тоже учитывать долю пути (первая станция — небольшая орда). Сохранить сложность/угрозу (Difficulty), кровавую луну и все API.
- **Детальнее зомби**: одежда слоями (порванная рубашка, штаны, обувь), разные телосложения, волосы/лысина, раны (тёмные пятна), бледная кожа с оттенками по биому, светящиеся глаза только ночью слабее, у элиты — уникальные детали. ZombieAnim: ковыляние, волочение ноги, у бегунов — рывки.
- **Лобби**: детализация (мокрый асфальт с отражениями — Material Asphalt + Reflectance 0.05, лужи, пар из люков (ParticleEmitter без текстуры), неоновые вывески, фонари с конусом света, автобусы детальнее, туман). LobbyUI — согласовать стиль с новым Tab-меню (кнопки/окна).
